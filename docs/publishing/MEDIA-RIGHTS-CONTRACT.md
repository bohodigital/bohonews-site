# Media rights contract

Every public image requires a private media-rights record and an approved public
reference. The record preserves creator, source URL, rights basis, license,
attribution, restrictions, retrieval date, original hash, derivative hashes,
caption, alt text, archival/current state, and contextual notes. Production
records must declare `aiGenerated: false` and a null illustration label.

The private gate validates safe raster signatures and exact hashes. The
responsive contract covers lead, card, square social, 4:3, 16:9, Open Graph, and
compact-mobile roles with explicit dimensions. The public article layout emits
dimensions, responsive-safe sizing, captions, and credits when media exists.

No How Biscuit imagery, AI-generated image or synthetic image is included in the
production package. Batch 1 includes 14 verified photographs and direct
official-document renders, each transformed into seven deterministic responsive
WebP derivatives.
